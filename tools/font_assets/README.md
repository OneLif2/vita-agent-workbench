runtime TTF loader: the C atlas and full original license are intended for compilation
into the Workbench application. The font identifier jetbrains refers to this Workbench-
produced bitmap, not to endorsement by JetBrains. This is **not** a Nerd Font.
There are no ligatures, CJK, Powerline/private-use icons, or runtime font discovery.

**Scope:** the terminal body uses this face when selected. 95 printable ASCII glyphs
(space through tilde), plus the existing Workbench heart marker (0x7f), deliberately
drawn separately; other bytes do not index this atlas. Body cell capacity is 8x14
*before* size multiplication or user-selected spacing. The actual ink width and height
vary per glyph. Header, menus, SSH byte stream and client-side font are unrelated.

## Rebuild/check offline

The checked-in ASCII masks are sufficient to compile on a VitaSDK host with no Python
font library installed. The compiled-atlas host check does not need the omitted TTF:

    python -B tests/font_atlas/run.py

After obtaining and verifying the pinned TTF, regeneration/check can run offline:

    python -B tools/gen_jetbrains_bitmap.py --check
    python -B tests/font_atlas/run.py

To intentionally regenerate use --write. Reference environment: CPython 3.12, Pillow
13.0.0, FreeType 2.14.3; use the same rasterizer/version to reproduce identical hinting.
A different renderer is not silently accepted: --check compares generated bytes against
the frozen headers, and both input files have pinned hashes. Raster recipe: TTF 12-pixel
em (not 12 points), FreeType BASIC layout with baseline at y=11; binary threshold 104/255,
8x14 cell with high bit left. The 95 ASCII masks must be distinct and only space empty;
the guarded canvas detects clipped glyphs. At 2x, 16x28 pixels are reserved before spacing.
